# Site photos & video

Drop your own media here to replace the stock imagery:

- `hero-loop.mp4` — the looping homepage background video (muted, 10–30 sec,
  1920×1080, ideally under 8 MB). Footage of members around the lunch table is perfect.
  If this file isn't present, the homepage shows a slow-zoom photo instead.

To swap the still photos, upload images into this folder and update the paths in
`lib/config.js` (e.g. `table: '/media/our-lunch-table.jpg'`).
